# Islamabad Specialist Hospital

Website project for Islamabad Specialist Hospital.

## Design skills — required for all frontend work

This project ships two project skills in `.claude/skills/`. Both are mandatory whenever building, styling, animating, or reviewing any UI in this repository:

- **frontend-design** (`.claude/skills/frontend-design/SKILL.md`) — visual design quality: aesthetic direction, typography, color tokens, layout, spacing, component states, accessibility. Read it before writing any markup or styles.
- **framer** (`.claude/skills/framer/SKILL.md`) — motion and interaction design: springs, scroll-driven reveals, micro-interactions, page transitions, reduced-motion support. Read it before adding any animation or interactivity.

Workflow for any UI task: load both skills first, state the aesthetic direction, build design tokens, then implement. Static polish follows frontend-design; everything that moves follows framer.

## Brand context

Healthcare brand — the design direction is calm competence and trust: clean, spacious, precise, warm. High contrast and generous type sizes (users skew older). Motion is smooth and reassuring, never playful or attention-grabbing near critical flows (appointments, contact, emergency info).
